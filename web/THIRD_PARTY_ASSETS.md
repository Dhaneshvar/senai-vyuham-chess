# Third-party 3D assets

The optional **Medieval** piece set loads static GLB character sculpts originally published with
[King's Gambit - Medieval 3D Chess](https://github.com/ade5791/rork-medieval-3d-chess).

Copyright King's Gambit contributors. Used under the MIT License included in the source project.
The application retains its procedural chess pieces as a fallback when these hosted models are
unavailable. Before public production deployment, mirror the GLB files onto infrastructure owned
by this project so availability does not depend on the original project's CDN.
